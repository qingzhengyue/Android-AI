# 提交前检查清单

## 资格与原创

- [ ] 学生均为 2026 年 6 月底前全日制在读研究生、本科生或专科生。
- [ ] 学生不超过 5 人，指导教师 1-2 人，不跨校组队。
- [ ] 作品无知识产权纠纷，未获本赛项国家级一等奖，未直接使用他人创意或成果。
- [ ] 代码、素材、模型和第三方服务的来源与许可证已记录。

## 材料

- [ ] `PPT-参赛队编号-参赛队名`，答辩使用。
- [ ] `说明书-参赛队编号-参赛队名.pdf`，不超过 30 页，符合字体和行距规范。
- [ ] MP4 不超过 1 分钟、80 MB，已穿插在 PPT 中，答辩人原则上入镜。
- [ ] PPT、说明书、视频均无学校及指导老师信息。
- [ ] 如有支撑材料，仅包含参赛学生参与成果，汇总为一个 A4 PDF。
- [ ] 支撑材料不匿名，参赛成员名字下有醒目红色下划线，文件名为 `参赛队编号-参赛队名.pdf`。

## 压缩包与发送

- [ ] 全部材料放入 `参赛队编号-学校名称-参赛队名` 压缩包。
- [ ] 邮件标题为 `2026年AI+智创未来（选拔赛认证材料）-负责人联系电话`。
- [ ] 发送至 `Robotguosai@163.com`，并按通知要求完成 QQ 群接龙。
- [ ] 已加入通知群并核对最新补充通知、报名时间、线上调试和抽签安排。

## 演示验收

- [ ] 新设备首次安装可启动，横竖屏切换不丢失关键状态。
- [ ] 教师和学生一键演示账号均可登录。
- [ ] 任务发布、学生编程、保存、提交、AI 初评、教师复核全链路通过。
- [ ] 断网时本地示例与结构评测仍可完成核心演示。
- [ ] APK、PPT、视频均在比赛使用设备上实测，另有离线备份。
